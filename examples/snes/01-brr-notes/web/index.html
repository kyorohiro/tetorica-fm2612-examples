SNES：BRR でメロディーと和音

実験的な useSoundChip('snes') で自作 BRR を読み込み、S-DSP の8ボイスを演奏します。ゲームの音色ファイルは不要です。

Ready.

有限のメロディーと和音を演奏し、終了後に音声リソースを解放します。Stop は読み込み中にも使えます。コードの変更は次の Play に反映されます。

ボイスは物理チャンネル 0〜7。ADSR / GAIN / 左右音量はチップのレジスタ値です。内部は 32,000 Hz 固定で、ブラウザーの出力レートに変換されます。

実験的実装です。SPC ファイルを演奏する CPU / ドライバーは動かさず、独立した S-DSP と BRR 音色を使います。
