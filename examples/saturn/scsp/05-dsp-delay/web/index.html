SCSP DSP：RAMを使うDelay

自作PCMを送信し、離鍵後も続くEchoと、Delay用64 KiB RAMの位置を確認します。

Ready.

Releaseは入力音だけを離鍵し、残響は続きます。Feedback変更は履歴を保ち、Time / Enable変更はringを消去します。Stopは音と残響を消去。ringは既存PCMの後ろへ必要時だけ確保し、clearRam:trueのresetまで予約を保ちます。

適用済みDSP命令

Play後に実チップから取得します。
Program / COEF / RAM / slotの適用済み設定


0.2.44の公開npm APIで、CPU-free SCSPの実コアを使います。JavaScriptは操作とソフトウェアによる演奏を担当し、DSP命令は音源コア内で実行されます。コードは40拍演奏し、2拍の残響を待って終了します。Stopは読み込み中も使えます。
