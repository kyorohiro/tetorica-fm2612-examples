ps1/spu/02-reverb · WEB / NODE

SPU：送信と共有リバーブ

2つのボイスを使い、個別Sendと1つの共有プリセット・左右Returnを比較します。

1つの共有SPU Reverb · 近似プリセット

Returnは元のdry音へ加算されます。SendをOffにしても既存の残響は続きます。StopはSPUごと解放して残響も消します。

Ready.

コード編集は次のPlayに反映されます。applyControls()は個別Send・共有preset・左右Returnを読み取り、演奏中も送ります。 startAudio()・sleep(秒)・console・encodePs1Adpcm()を使えます。初期化中もStopでき、終了・エラー・ページ移動時に解放します。

PCM→ADPCMはソフトウェアの準備処理です。SPUは符号化サンプルを固定44,100 Hzで再生し、デバイス出力時だけリサンプリングします。音源へ送るVoice volumeを抑えて内部加算の余裕を作り、host gain 0.6を1回だけ適用します。
