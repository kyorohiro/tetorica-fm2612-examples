DX7：SysEx と音色選択

1音色または32音色の SysEx を読み込み、音色を選んでメロディと和音を試聴します。

未選択なら同梱の自作32音色を使います。ファイルを選択し、Load bank → 音色を選択 → Play の順に操作します。


Ready.

音色番号は0始まり。loadSysex() の完了を待ってから selectVoice() と noteOn() を呼びます。不正なファイルでは前に読み込めた音色を保持します。

const dx7 = await useSoundChip('dx7');
await dx7.loadSysex(bankBytes);
console.log(dx7.voices); // [{index, name}, ...]
dx7.selectVoice(0);
dx7.noteOn(60, 100); // MIDI C4, velocity 100
await beat(1);
dx7.noteOff(60);
