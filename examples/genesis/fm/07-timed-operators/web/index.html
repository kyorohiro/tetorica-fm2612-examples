Software timing：予約はソフトウェアが行い、OperatorとEnvelopeはYM2612が処理します。build()は操作を記録し、compile()は基準状態から書き込み列を予測します。どちらも音源を書き換えません。

MULTとDTは同じレジスタです。MULTだけの予約は、実行時のDTを保ちます。schedule()の完了は「受付完了」で、演奏完了ではありません。同名予約は置換・再開始され、clearSchedule()は未来の操作を取り消します。適用済みの値は戻りません。

Stopは出力を閉じ、音源と予約を破棄します。Nativeの予約実行は対象外です。この例では実ゲーム音色・曲・サンプルは使いません。
