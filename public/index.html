機能ごとに小さく分けた音源サンプル集。各フォルダーに説明、Web の実行ページ、Node.js の WAV 出力例があります。読み込みから音源操作、出力まで、それぞれのコードに省略せず記述しています。

npm install
npm run dev

公開済み npm パッケージを import して使います。Web は PCM を生成して再生、Node は WAV を保存します。各例のコードは共通ヘルパーを使わず、重複も含めて全部載せています。

Loading examples…

フォルダーの読み方

examples/genesis/fm/01-single-note/
├── README.md       説明・実行方法
├── web/
│   ├── index.html  この例だけを試すページ
│   └── main.js     読み込み・音源操作・再生・WAV 保存
└── node/
    └── main.mjs    読み込み・音源操作・WAV 保存

一覧から Web 版を開くか、repository ルートで Node 版を実行してください。

node examples/genesis/fm/01-single-note/node/main.mjs
# output/genesis-fm-01-single-note.wav に保存

Node.js 22 以降。Node 版で保存した WAV は音声プレイヤーで再生できます。Web 版の音声は Play を押して開始します。

npm run build で静的サイトを dist/ に生成します。JS・WASM・ライセンスを含む npm package も同梱されます。
