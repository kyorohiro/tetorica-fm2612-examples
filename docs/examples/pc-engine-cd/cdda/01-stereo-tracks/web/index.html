CD-DA：ステレオとトラック操作

自作の44.1 kHz stereo PCM16 WAVを2トラックに分け、Pause／Resume／Seek、曲の切り替えと再演奏を試します。

Ready.

編集は次のPlayに反映されます。外部ファイルなしで演奏でき、終了時に音声リソースを解放します。読み込み中もStopできます。

CD-DAの入力は44,100 Hz・stereo・PCM16 RIFF WAVです。トラック範囲は元WAVのフレーム単位、Seekとoffsetは選択トラック内の秒です。
