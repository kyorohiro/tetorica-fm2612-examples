OPL2：オペレーター・波形・LFO

YM3812の2オペレーターをFM／加算接続で比較し、4種類の波形とハードウェアLFOを試します。

Ready.

編集は次のPlayに反映されます。opl、OPL_PRESETS、sleep(秒)、consoleが使えます。終了とStopのどちらでも音声リソースを解放します。

CH0のoperator 0がモジュレーター、operator 1がキャリアです。TLは0が最大、63が最小。algorithm 0はFM、1は加算接続です。波形1〜3では倍音や直流成分も変わるため、同じ音程設定でも響きが変わります。

OPL2はモノラルです。LFOの速さはハードウェア固定で、深さを全体で設定し、AM／vibratoを各オペレーターで有効にします。
