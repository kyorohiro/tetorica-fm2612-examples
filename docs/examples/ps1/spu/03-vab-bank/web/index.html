SPU：VABのProgramとTone

標準Sony VABを開き、元のADPCM・ADSR・基準音程を使って1音を試します。選択するだけでは音は鳴りません。

Load demo または手元のVABを選んでください。

Bank / Tone · 読み込みだけでは音声を開始しません C4などの音名。元のCenter / Shiftから基準周波数を設定します。

Audio idle.

No bank selected.

対応は標準VAB v6/v7のcombined .vab（最大1 MiB）。Noiseや不正なADPCMなど、試奏できないToneには理由を表示します。Program番号は飛び番のままです。

Shared reverbはOffで試奏します。元ToneのReverb sendは保持しますが、VABには共有リバーブ設定がありません。Key範囲・Vibrato・Portamentoは表示用の記録で、自動演奏ドライバは再現しません。

preparedは選択時にprepareVabTone()で検証したデータのコピーです。startAudio()・sleep(秒)・note・consoleが使えます。既定は0.6秒で離鍵し、元のReleaseの後0.15秒で音源を閉じます。終了・Stopには8 msのソフトウェア出力フェードを使い、元のADSRは変更しません。音量の自動正規化はせず、host gain 0.6を1回だけ適用します。

書き出しはexportVab(bank, {toneNumber})です。元のProgram番号と生ADPCMを保持した標準VABを保存し、Tone 0 / Sample 1へ再配置します。試奏用コードの編集を元のVABへ逆変換する機能ではありません。
