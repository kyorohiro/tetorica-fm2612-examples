YM2149：音量レジスタを動かす

R8の固定Volumeを予約し、Toneの音程と別周期で音量を変化させます。ハードウェアEnvelopeは使いません。

Ready.

ym、setBpm、beat(拍)、sleep(秒)、consoleが使えます。初期設定は8拍で終了します。setBpmは音程変更の間隔を変え、modulationHzは秒あたりのVolumeパターンの繰り返しを変えます。

No compiled trace yet.

Offset (seconds)RegisterValue

予約とパターンはソフトウェア制御です。Tone生成と16段階の非線形VolumeはYM2149の機能です。初期設定は16書き込み×50回/秒＝800書き込み/秒。出力は連続PCMではなく、固定Volumeコードを段階的に変えた結果です。

clearScheduleは未来の書き込みだけを取り消します。最後のVolumeを無音に戻すため、続いてkeyOffも行います。詳しくはREADMEとR13のSync-buzzer。
