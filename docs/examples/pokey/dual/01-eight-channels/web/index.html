Dual POKEY：2チップ・8つの実ボイス

独立した4CHコアを2個作り、計8つの実ボイスをホスト側でモノラル加算します。各フレーズの後半はAだけを消音し、Bの4ボイスが鳴り続けます。

Ready.

編集は次のPlayに反映されます。startAudio()でpokeys・transports・contextを取得し、sleep(秒)・consoleを使えます。初期化中もStopでき、終了・エラー・ページ移動時に音声リソースを解放します。

各チップの物理CHは0〜3。1チップを8CHに拡張せず、独立した2コアが4ボイスずつ鳴ります。どちらも入力クロック1,789,773 Hzです。左右Panはチップに存在しません。この例はホスト側のモノラル加算です。

出力gainは0.25を1回だけ適用。POKEYはmonoで、左右に同じPCMを出します。WebとNodeは同じ10 Hz DC除去を使い、正規化はしません。
