仕組み・制限

build()は操作だけを記録。compile()は取得済みsnapshotから予測し、音源もsnapshotも変更しません。比較結果は上のログに表示します。実演奏の書き込み履歴ではありません。

schedule()の完了は受付完了です。R90の部分更新は実行時に解決され、後からOnにした無音のCH2 Gateが残ることを例内で確認します。R8EのNoise resetは値が同じでも省略しません。

予約はソフトウェア機能で、音源の追加機能ではありません。Wave RAM／Voice PCM転送とSynthのソフトウェアEnvelope noteOn/offはレコーダーの対象外。raw keyOffは即時Gate offです。Native予約は未対応。Stopは出力を閉じて予約と音源を破棄します。
