SCSP DSP：Gain / IIRを命令から作る

フィールド表記を512語へassembleし、MIXS0 → DSP → EFREG0の音と係数を確認します。

Ready.

GainはCOEF0 / 4096、IIRは前の出力×COEF1＋新しい入力×COEF2。係数は符号付きQ12のチップコードです。IIRのつまみはCOEF1＋COEF2=4096を保ちます。波形RAMを使わず、発音とTEMP履歴を保って変更できます。

適用済みDSP命令

Play後に実チップから取得します。
Program / COEF / RAM / slotの適用済み設定


0.2.44の公開npm APIで、CPU-free SCSPの実コアを使います。JavaScriptは操作とソフトウェアによる演奏を担当し、DSP命令は音源コア内で実行されます。コードは40拍演奏し、2拍の残響を待って終了します。Stopは読み込み中も使えます。
