SPC ファイル再生（実験的）

SPC700 と S-DSP を AudioWorklet で動かします。同梱のオリジナル短音、または手元の SPC ファイルを再生できます。

0.00 s

Ready. 同梱音源はループする 2000 Hz の短音です。

Native SPC: 32,000 Hz · stereo / AudioContext output: starts after Play

Pause / Resume は位置を維持します。Stop は読み込み中にも使え、音声リソースを解放します。次の Play は元の SPC から再開します。ファイル変更時も停止します。

実験的実装。内部は固定 32,000 Hz、出力のみ AudioContext のレートへ変換します。ID666 / xid6 の長さ・フェードは適用せず、指定した再生上限で停止します。ゲームによっては再現できないことがあります。
