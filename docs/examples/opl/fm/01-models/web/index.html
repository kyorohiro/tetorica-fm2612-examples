OPL family：4モデルの基本発音

YM3526、YM3812、Y8950のFM部分、YMF262を同じ高級APIで鳴らします。A4のあと、ベルとオルガンの短いメロディーを演奏します。

Ready.

編集とチップ選択は次のPlayに反映されます。sleep()の単位は秒です。初期化中もStopが使え、終了時には音声リソースを解放します。

WebはMainで音符を操作し、AudioWorkletで連続的にPCMを生成します。OPL／OPL2／Y8950のFM出力はモノラルで、左右の両方に送られます。YMF262は18物理CHとステレオを持ちます。この例は共通の2オペレーター音色を使います。
